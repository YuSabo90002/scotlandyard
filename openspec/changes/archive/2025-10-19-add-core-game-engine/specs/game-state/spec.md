## ADDED Requirements

### Requirement: プレイヤーの管理

ゲームは1人の怪盗Xと2-5人の刑事（計3-6人）で構成されなければならない（MUST）。マルチプレイヤー時は、3-6人のプレイヤーが参加し、各プレイヤーが1つ以上の刑事役を担当できなければならない（MUST）。

#### Scenario: プレイヤーの初期化

- **WHEN** ゲームが開始される
- **THEN** 怪盗Xと刑事がそれぞれの開始位置に配置される
- **AND** 各プレイヤーに初期チケットが配布される

#### Scenario: 不正な刑事の人数

- **WHEN** 刑事の人数が1人以下または6人以上でゲームを開始しようとする
- **THEN** バリデーションエラーが発生する

#### Scenario: 不正なプレイヤー数（マルチプレイヤー）

- **WHEN** マルチプレイヤーで2人以下または7人以上でゲームを開始しようとする
- **THEN** バリデーションエラーが発生する
- **AND** 最低3人必要である旨のエラーメッセージが返される

#### Scenario: マルチプレイヤーでの刑事の割り当て

- **WHEN** マルチプレイヤーモードでゲームが開始される
- **THEN** 1人のプレイヤーが怪盗X役を担当する
- **AND** 残りのプレイヤー（最低2人）が2-5人の刑事を分担して操作する
- **AND** プレイヤー数が刑事数より少ない場合、各プレイヤーが複数の刑事を操作する

#### Scenario: 最小プレイヤー数（3人）

- **WHEN** 3人のプレイヤーでゲームを開始する
- **THEN** 1人が怪盗X、2人が刑事役（各プレイヤーが2-3人の刑事を操作）を担当する
- **AND** 刑事役のプレイヤーは最低2人いる
- **AND** ゲームが正常に進行する

### Requirement: チケットシステム

各プレイヤーは、Taxi、Bus、Undergroundのチケットを一定数保有し、移動時に消費しなければならない（MUST）。

#### Scenario: チケットの初期配布

- **WHEN** ゲームが開始される
- **THEN** 刑事にはTaxi 10枚、Bus 8枚、Underground 4枚が配布される
- **AND** 怪盗XにはTaxi 4枚、Bus 3枚、Underground 3枚、Black 5枚、Double Move 2枚が配布される

#### Scenario: チケットの消費

- **WHEN** プレイヤーが移動する
- **THEN** 使用した交通手段のチケットが1枚減少する

#### Scenario: チケット不足

- **WHEN** プレイヤーが保有していないチケットで移動しようとする
- **THEN** 移動が拒否される

### Requirement: ブラックチケット（怪盗X専用）

怪盗Xのみが使用できるブラックチケットは、任意の交通手段（Taxi/Bus/Underground/Ferry）として使用できなければならない（MUST）。

#### Scenario: ブラックチケットの使用

- **WHEN** 怪盗Xがブラックチケットを使用する
- **THEN** Taxi、Bus、Underground、Ferryのいずれかの交通手段で移動できる
- **AND** 使用した実際の交通手段は刑事側に公開されない

#### Scenario: ブラックチケットでのFerry利用

- **WHEN** 怪盗XがブラックチケットでFerryルートを利用する
- **THEN** Ferryコネクションで接続されたノードに移動できる
- **AND** 使用したチケットはブラックと表示される（Ferryとは表示されない）
- **AND** 実際にFerryを使用したことは刑事側に公開されない

#### Scenario: 刑事のブラックチケット使用試行

- **WHEN** 刑事がブラックチケットを使用しようとする
- **THEN** エラーが発生する

### Requirement: ダブルムーブカード（怪盗X専用）

怪盗Xのみが使用できるダブルムーブカードは、1ターンに2回連続で移動できなければならない（MUST）。

#### Scenario: ダブルムーブカードの使用

- **WHEN** 怪盗Xがダブルムーブカードを使用する
- **THEN** ダブルムーブカードが消費される
- **AND** 1回目の移動用チケットを選択する
- **AND** 選択したチケットを保有していることが検証される
- **AND** 1回目の移動を実行し、チケットが消費される
- **AND** 1回目の移動完了後、2回目の移動用チケットを選択する
- **AND** 2回目のチケットを保有していることが検証される
- **AND** 2回目の移動を実行し、チケットが消費される
- **AND** 2回の移動が完了するまで刑事のターンに移行しない

#### Scenario: ダブルムーブカード使用時のチケット不足（1回目）

- **WHEN** ダブルムーブカード使用開始時に選択した1回目のチケットを保有していない
- **THEN** ダブルムーブの使用が拒否される
- **AND** ダブルムーブカードは消費されない

#### Scenario: ダブルムーブカード使用時のチケット不足（2回目）

- **WHEN** 1回目の移動完了後、2回目のチケットを選択したが保有していない
- **THEN** 2回目の移動が拒否される
- **AND** 1回目の移動は確定しており、ダブルムーブカードと1回目のチケットは消費済み
- **AND** 保有している別のチケットを選択し直す必要がある

#### Scenario: ダブルムーブカードとブラックチケットの併用

- **WHEN** ダブルムーブカード使用時にブラックチケットを選択する
- **THEN** 1回目または2回目の移動でブラックチケットを選択できる
- **AND** 両方の移動でブラックチケットを選択することもできる
- **AND** ブラックチケットで移動した際の交通手段は刑事側に公開されない

#### Scenario: 刑事のダブルムーブカード使用試行

- **WHEN** 刑事がダブルムーブカードを使用しようとする
- **THEN** エラーが発生する

### Requirement: ターン管理

ゲームは怪盗Xと刑事が交互に行動するターン制でなければならない（MUST）。

#### Scenario: ターンの進行

- **WHEN** 怪盗Xが移動を完了する
- **THEN** 刑事のターンに移行する
- **AND** すべての刑事が移動を完了したら怪盗Xのターンに戻る

#### Scenario: ダブルムーブ使用時のターン進行

- **WHEN** 怪盗Xがダブルムーブカードで2回移動を完了する
- **THEN** 刑事のターンに移行する
- **AND** ターン数は1増加する（2回移動しても1ターンとしてカウント）
- **AND** 怪盗Xの移動回数は2増加する

#### Scenario: ターン数のカウント

- **WHEN** 全プレイヤーが1回ずつ移動する
- **THEN** ターン数が1増加する
- **AND** 最大24ターンでゲームが終了する

#### Scenario: 怪盗Xの移動回数のカウント

- **WHEN** 怪盗Xが通常移動を行う
- **THEN** 移動回数が1増加する

- **WHEN** 怪盗Xがダブルムーブを使用する
- **THEN** 移動回数が2増加する

### Requirement: 怪盗Xの位置公開

怪盗Xの位置は、怪盗Xの移動回数が3, 8, 13, 18, 24回目の移動後に刑事側に公開されなければならない（MUST）。

#### Scenario: 位置公開（移動回数ベース）

- **WHEN** 怪盗Xの移動回数が3, 8, 13, 18, 24のいずれかに達する
- **THEN** 怪盗Xの現在位置が刑事側に公開される

#### Scenario: 位置非公開（移動回数ベース）

- **WHEN** 怪盗Xの移動回数が3, 8, 13, 18, 24以外である
- **THEN** 怪盗Xの現在位置は公開されず、使用したチケット種類のみが公開される

#### Scenario: ダブルムーブ使用時の位置公開タイミング

- **WHEN** ダブルムーブの1回目の移動で移動回数が位置公開タイミング（3, 8, 13, 18, 24のいずれか）に達する
- **THEN** 1回目の移動完了時点で怪盗Xの位置を一時的に公開する
- **AND** その後、2回目の移動を行い、移動完了後は再び位置を隠す

- **WHEN** ダブルムーブの2回目の移動で移動回数が位置公開タイミングに達する
- **THEN** 2回目の移動完了後の最終位置が公開される
- **AND** 1回目の移動後の中間位置は公開されない（位置公開タイミングではないため）

### Requirement: ゲーム状態の取得

各プレイヤーは自分の視点でゲーム状態を取得できなければならない（MUST）。

#### Scenario: 刑事の視点

- **WHEN** 刑事がゲーム状態を取得する
- **THEN** すべての刑事の位置が見える
- **AND** 怪盗Xの位置は公開ターンでのみ見える
- **AND** 怪盗Xが使用したチケット履歴が見える

#### Scenario: 怪盗Xの視点

- **WHEN** 怪盗Xがゲーム状態を取得する
- **THEN** すべての刑事の位置が見える
- **AND** 自分の位置とチケット残数が見える
